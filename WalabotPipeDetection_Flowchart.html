🔍 Walabot Pipe Detection System Flowchart

Matlab Implementation for In-Wall Pipe Detection

▶
START: Initialize System
Clear workspace, load libraries, set configuration parameters
clear all; close all; clc;
1
Load Walabot API Assembly
Import .NET assembly and create API instance
NET.addAssembly('WalabotAPI.NET.dll')
2
Set Settings Folder
Configure Walabot database location
API.SetSettingsFolder(path)
3
Connect to Walabot Device
Establish USB communication with Walabot hardware
API.ConnectAny()
4
Set Scan Profile
Configure SHORT_RANGE_IMAGING profile for wall penetration
API.SetProfile(PROF_SHORT_RANGE_IMAGING)
5
Configure Arena (Scanning Volume)
Set X, Y, Z ranges and resolutions in Cartesian coordinates
API.SetArenaX/Y/Z(min, max, resolution)
6
Set Advanced Parameters
Configure dielectric constant and sensitivity threshold
API.SetAdvancedParameter(), API.SetThreshold()
7
Set Dynamic Filter
Disable filtering for static pipe detection
API.SetDynamicImageFilter(FILTER_TYPE_NONE)
8
Start Walabot System
Prepare system for scanning operations
API.Start()
9
Calibrate System
Remove static background signals from wall surface
API.StartCalibration(), API.GetStatus()
?
Calibration Complete?
Wait for STATUS_SCANNING
↻
MAIN DETECTION LOOP (Start)
Continuous scanning for pipe detection
10a
Trigger Scan
Initiate RF scan and record signals
API.Trigger()
10b
Get Imaging Targets
Retrieve detected pipes with position, type, and amplitude
targets = API.GetImagingTargets()
10c
Get Raw Image Slice
Obtain 2D projection for visualization
API.GetRawImageSlice()
10d
Process & Display Results
Show detected pipes, positions, and image visualization
Display target info and raw image
?
Continue Scanning?
Loop until user stops (Ctrl+C)
11
Stop Walabot System
Halt scanning operations
API.Stop()
12
Disconnect Device
Close USB communication
API.Disconnect()
13
Cleanup API
Release resources and clear API instance
API.Clean()
■
END: System Shutdown Complete
All resources released, ready for next session
